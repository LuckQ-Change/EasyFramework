Windows x64 IL2CPP 构建尝试停在本机缺少 Visual Studio C++ 编译器及 Windows SDK，详见 `Logs/BuildIL2CPP-20261014.log`。Android IL2CPP 已完成 AOT 构建，但 APK 未在物理设备上运行；Windows IL2CPP 的原生链接仍需安装工具链后验证。分辨率窗口按锚点计算轮廓，`LayoutGroup` 的实际排列在 Game 视图验收。可选 YooAsset/HybridCLR 适配器需要项目安装对应包并启用宏后单独构建。

## 演示入口

打开 `Assets/Scenes/FrameworkShowcase.unity` 进入 Play Mode。第二张“UI 工作台”卡片打开页面，蓝色面板显示 Disabled 状态，右侧循环列表可滚动，再次点击卡片关闭页面。`Tools/EasyFramework/UI/UI Editor` 可查看真实 Prefab 的引用、状态、适配、动画和校验页；`Tools/EasyFramework/UI/Tween Timeline` 可拖动片段进度。
