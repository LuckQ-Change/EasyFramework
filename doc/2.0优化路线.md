# EasyFramework 2.0 优化路线

2.0 收口到核心、系统基础、适配层和工具层。YooAsset + HybridCLR 作为随框架维护的可选组合，纳入真实 Player 发布验收。纯本地工程和在线更新工程共用装配、资源所有权和 UI 工具。

实施顺序为 **固定基线 → UIState 和时间轴编辑 → 核心与 OnGUI Debug → 资源产线和更新组合 → 统一动画播放与事件轨 → 发布验证**。2.0 统一采用新 API、资产配置和编辑入口。

## 1. 分层与系统职责

### 核心

Core 是独立 C# 程序集，负责模块装配、依赖校验、初始化与就绪、失败回滚、关闭顺序、帧时钟、作用域和基础日志。

- **保留**分阶段初始化、失败回滚和逆序清理。
- **退役**静态 `ModuleRegistry`、用整数 `order` 表达依赖、运行中改写根模块图和按名称从 `Resources` 推断启动配置。模块间依赖通过所属宿主取用，前端入口可按当前作用域查询模块。
- **重做**为唯一显式入口。入口声明模块工厂和依赖。宿主在启动前检查缺失和循环，依赖就绪后才交给消费者。作用域关闭时先取消任务，再等待已登记任务收尾，最后逆序释放句柄。
- **缩减 `FrameworkLauncher` 的职责**，由它把 Unity 场景入口、帧循环和退出接到宿主。预热、更新、首流程和诊断由所选系统显式装配。 [现有模块管理](../Runtime/Core/ModuleManager.cs) · [现有启动入口](../Runtime/Bootstrap/FrameworkLauncher.cs)

### 系统基础

系统按需装配。表中的依赖指该能力运行所需的接口和服务。

| 系统 | 职责与依赖 | 2.0 决定 |
| --- | --- | --- |
| Event | 类型化派发、订阅顺序、异常隔离。依赖 Core 作用域。 | 保留派发语义。订阅改用可释放句柄，退役全局入口。 |
| Timer | 延迟、循环、取消。依赖帧时钟。 | 保留长帧和重入行为，明确缩放与非缩放时间，调度器归宿主。 |
| Pool | 创建、重置、借出、归还和销毁。依赖对象工厂。 | 保留重复归还和跨池检查，明确关闭时借出对象如何收尾。Unity 对象操作交给适配器。 |
| Tween | 插值、缓动、Sequence、播放句柄。依赖帧时钟。 | 保留数学和编排，退役静态队列。停止一个宿主只结束该宿主的动画。 |
| Asset | 加载合并、租约、预热、缓存和并发。依赖资源后端。 | 保留所有权模型。后端同时提供运行时解析和编辑期校验。资源策略改用适配器配置。 |
| Scene | 加载、激活、卸载、操作句柄和取消后的清理。依赖场景适配器。 | 已提交的底层操作完成后收尾，作废结果不得接管当前场景。通过只读状态和状态事件向项目界面提供进度与错误。 |
| Audio | 音乐、音效、音量、声道和片段租约。依赖音源与片段提供者。 | 保留播放与回收。直接片段和按地址加载分别装配，移除对 `AssetModule.Instance` 的查找。 |
| UI | 页面、模态、焦点、常驻 HUD、Node、虚拟列表。依赖 uGUI 与 Prefab 提供者。 | 保留强类型 View 和绑定。重做页面清单，移除多处地址和反射查找。动画与点击音效按需接入。 |
| UIState / UITimeline | 状态控制受控字段。时间轴负责采样、播放与事件，运行时依赖 Tween 调度。 | 重做状态数据、统一播放器与编辑界面。UIState 可独立使用，普通页面可在无 Timeline 时开关。 |
| Procedure | 可选的异步进入、退出和流程切换。依赖作用域与工厂。 | 保留流程语义，以显式工厂替代反射构造，从 Launcher 移出首流程选择。 |
| Network / Session | 连接、收发、状态观察、派发与会话清理。依赖传输、编解码和主线程派发。 | 保留分帧、队列预算和旧连接隔离。TCP 下移为可选实现，重连策略通过接口接入。 |
| Hotfix / Update | Hotfix 管元数据、程序集和入口。可选更新协调器负责选版本、下载、校验和交接。 | 保留 `IHotfixLoader`。重做失败语义和组合启动，统一由更新协调器选版本。 |
| Storage | 可选持久化读写与版本迁移。 | 列为后续增量，2.0 优先交付已有系统的边界和工具闭环。 |

安装 UI 和本地 Prefab 提供者即可创建、打开和关闭页面。Audio、网络、热更和第三方资源包按需加入。Scene 取消区分提交前和提交后。Unity 延迟激活会阻塞后续异步操作，适配器负责让已提交操作完成收尾并卸载作废结果。 [Tween 调度](../Runtime/Tween/TweenScheduler.cs) · [场景模块](../Runtime/Scene/SceneModule.cs) · [音频资源依赖](../Runtime/Audio/AudioModule.cs) · [网络入口](../Runtime/NetWork/NetworkModule.cs) · [Unity 场景激活与队列](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AsyncOperation-allowSceneActivation.html)

### 适配层

Unity 主循环、uGUI、SceneManager、AudioSource、直接引用包、YooAsset、TCP 和 HybridCLR 分别实现对应契约。YooAsset 和 HybridCLR 各自有独立程序集，通过在线更新组合模板接入。普通 UI 可用本地 Prefab 提供者，Hotfix 可单独使用其他字节来源。

YooAsset 适配器负责包、清单、下载、加载与收集校验。HybridCLR 适配器负责补充元数据、加载程序集和调用约定入口。**更新协调器统一选择本次启动版本**，Asset 和 Hotfix 消费选定的结果。现有 YooAsset Loader 在初始化时自行请求版本，HybridCLR 的元数据失败只记日志，这两处改为由组合统一协调并报告阶段结果。 [YooAsset 初始化](../Adapters/YooAsset/YooAssetLoader.cs) · [HybridCLR 桥接](../Adapters/HybridCLR/HybridCLRLoader.cs)

### 工具层

- **安装向导**提供最小本地、标准 UI、在线更新三个起点。选择入口场景和组合，预览改动，再创建并关联配置。
- **页面只登记一次。** 清单持有稳定页面 ID、Prefab 键、导航策略和工厂绑定。向导创建页面即登记，开页、编辑校验和构建使用同一份清单。退役 Prefab 手填地址、生成的 `[UIPrefab]` 地址和运行时反射查找。构建检查当前配置可达的页面，草稿可以独立存在。
- **更新构建工具**检查 SDK、目标配置和收集地址，生成发行记录并复核每个产物。后端提供自己的编辑期校验，退役通用 UI 校验器中的 YooAsset 反射和全 `Assets` 扫描。
- **UI 工作台**统一绑定、状态、动画和问题定位。Editor 采用 UI Toolkit、UXML 和 USS，Inspector 提供高频操作与定位入口。运行时页面使用 uGUI，运行时诊断使用 OnGUI。 [现有构建校验](../Editor/UI/Validation/UIValidator.cs) · [Unity 自定义 Inspector](https://docs.unity3d.com/2022.3/Documentation/Manual/UIE-HowTo-CreateCustomInspector.html) · [Unity 样式表](https://docs.unity3d.com/2022.3/Documentation/Manual/UIE-USS.html)

## 2. YooAsset + HybridCLR 组合

### 配置与出包

| 步骤 | 操作与产出 |
| --- | --- |
| 1. 固定构建基线 | 安装向导选择在线更新组合，固定 Unity、YooAsset、HybridCLR、目标平台、架构与 IL2CPP 构建配置。首轮以 Unity `2022.3.62f2` 和仓库文档中的 YooAsset `3.0.7` 为验证起点，HybridCLR 版本随实测组合锁定。 |
| 2. 建立本地启动入口 | 主包内置启动页、进度、错误与重试界面，在离线或热更入口失败时仍可运行。AOT 程序集提供稳定入口契约，热更程序集引用契约。热更页面工厂随热更程序集交付，由入口绑定到子作用域。 |
| 3. 配置 HybridCLR | 安装对应 IL2CPP 支持，在 HybridCLR Settings 登记热更程序集，执行所选版本的构建生成步骤。归档正式 Player 对应的 AOT 产物和兼容标识。同一 Player 的后续更新使用归档中的匹配元数据。 |
| 4. 配置 YooAsset | 设置包名、别名、主备 CDN、超时及下载并发。热更 DLL 和需要下载的元数据按 `.dll.bytes` 收集到稳定地址。标记启动必需资源，更新阶段预下载它们及其依赖，其余资源按需加载。 |
| 5. 生成并发布发行记录 | 绑定发行 ID、Player 基线、目标平台与构建类型、各包清单版本、AOT 元数据集、DLL 地址与依赖顺序、入口契约和校验摘要。先上传并验证 Bundle、包清单和发行记录，最后切换渠道指针。上一份完整版本留作回退。 |

**一个发行版本包含整套资源和代码。** 主备 CDN 提供同一套文件。版本回退时切换整份发行记录。AOT 基线、裁剪结果或桥接契约超出已有 Player 的兼容范围时，走新 Player 发布。 [现有 YooAsset 配置](模块职责/Asset.md) · [HybridCLR 程序集配置](https://www.hybridclr.cn/docs/basic/hotupdateassemblysetting) · [打包流程](https://www.hybridclr.cn/docs/basic/buildpipeline) · [AOT 元数据归档](https://www.hybridclr.cn/en/docs/beginner/generic)

### 启动顺序

1. **本地宿主就绪。** 本地启动页、错误页和已启用的 Debug 可用。此时显示「本地就绪」，热更入口尚未开放。
2. **锁定候选版本。** 读取渠道指针和发行记录，检查本机 Player 基线、目标平台和入口契约。一次启动只处理一个候选，重复点击重试共用当前操作。
3. **预取清单与必要文件。** 按发行记录锁定各包版本，预取指定清单，计算并下载启动必需资源。清单切换在远程页面持有租约前完成。使用 YooAsset 3.0.7 指定版本的预取与加载接口分开准备候选和启用清单。 [YooAsset 预取实现](https://github.com/tuyoogame/YooAsset/blob/3.0.7/Assets/YooAsset/Runtime/ResourcePackage/Operations/PrefetchManifestOperation.cs) · [包接口](https://github.com/tuyoogame/YooAsset/blob/3.0.7/Assets/YooAsset/Runtime/ResourcePackage/ResourcePackage.cs#L144-L172)
4. **完成装载前校验。** 检查必需资源、AOT 元数据、DLL 的版本、依赖和摘要。校验通过后记录本次待确认启动，再开始热更装载。
5. **补元数据、载程序集、执行入口。** 先补所需 AOT 元数据，再按依赖顺序加载热更程序集。固定入口只执行一次，接收显式上下文并绑定自己的页面工厂与子作用域。入口成功后开放整套远程内容。 [HybridCLR 加载和运行](https://www.hybridclr.cn/docs/basic/runhotupdatecodes) · [补充元数据时机](https://www.hybridclr.cn/en/docs/beginner/generic)
6. **确认更新就绪。** 入口返回就绪后，将发行记录写为最后可用版本，释放本次启动临时持有的字节资产和租约。后续资源按已选定的清单加载。

### 失败处理

失败处理以**第一次向进程补 AOT 元数据或加载程序集**为界。此前可以放弃候选并清理后重试。进入装载后，通过干净重启执行版本回退。 [HybridCLR 热重载能力说明](https://www.hybridclr.cn/docs/8.5.0/business/hotfix)

| 失败点 | 处理 |
| --- | --- |
| 配置不完整、Player 基线或目标不匹配 | 停在本地错误页，显示发行 ID、期望基线和实际值。入口执行次数为零。回退候选必须完整、兼容且已经验证。 |
| 超时、断网、文件缺失、空间不足、摘要不符 | 对可恢复错误有限重试，可切同版本备用 CDN。放弃候选时结束下载和读取作用域，再回退整个兼容版本。首次安装且未配置完整本地版本时保留重试入口。 |
| 元数据或 DLL 装载失败 | 返回明确阶段、程序集和错误码，停止后续装载与入口。清理仍可释放的句柄，本地诊断继续可用。 |
| 入口抛错、未就绪或进程中断 | 关闭候选子作用域，保留上一次已确认版本。下次干净启动识别未确认发行，选择兼容旧版本，避免循环尝试同一个失败候选。 |

热更协调器按阶段记录失败，所需步骤全部成功后执行组合入口。 [热更启动链](../Runtime/HotUpdate/Startup/HotUpdateStartup.cs)

### 组合验收

- **同一个 IL2CPP Player** 清缓存启动 R1，再在线升级到 R2。测试程序集输出和测试资源都显示 R2，入口只执行一次。测试调用覆盖所需的 AOT 补充元数据。
- **缓存、离线和回退**。完整缓存后断网，进入允许使用的已验证版本。渠道切回 R1 后，干净重启恢复成套的 R1 代码和资源。首次离线且缺缓存时验证本地错误页。
- **故障注入**。覆盖错误平台、错误 Player 基线、缺包、损坏 DLL、下载中断、元数据失败、装载后入口异常及中途终止进程。记录失败阶段、发行 ID、包和文件。验证入口无重复、版本无混用、重试有上限。
- **可选性**。未安装两套 SDK 的独立工程使用本地模板通过构建。Editor 模拟验证配置，组合以真实 IL2CPP Player 验收结果放行。

## 3. 重点工具的操作与验收

### UIState

- **操作**。在 Inspector 设置运行时初态、查看状态和选中节点的覆盖，点击跳到工作台。工作台选状态，多选节点和受控字段，一次加入。支持「仅看覆盖项」、原地改值和单字段恢复基准。直接编辑表格会提交。在隔离画布调整后，点击「记录覆盖」才提交。
- **重做**。控制器持有稳定状态 ID、初始 ID、目标字段、基准和覆盖。退役逐节点 `UIElement`、运行时扫子树、`Awake` 自动重录和全局 Inspector 自动捕获。状态切换先算最终值，只写发生变化的字段。State 和 Timeline 同时声明一个字段时，在工作台定位冲突。
- **验收**。10 个节点和 3 个状态在同一面板配置，批量加入一次 Undo。改名、排序、预览后保存和重开，初态一致。预览产生零资产差异、零运行时状态事件。隐藏切隐藏无额外激活，嵌套控制器和实时字段互不覆盖。 [状态控制器](../Runtime/UI/State/UIStateController.cs) · [属性应用](../Runtime/UI/State/UIStateTargetAccess.cs)

### UITimeline

- **操作**。左侧固定轨道名，中间共享标尺和播放头，右侧编辑选中项。**时间区滚轮以鼠标指向时间为锚点缩放整条时间轴**。中键平移，`F` 适应整段，侧栏滚轮保留纵向滚动。拖播放头只取样，拖片段或标记才改资产，一次手势一项 Undo。
- **重做**。普通动效、进退场和默认淡入淡出共用一个播放器。播放器负责完成、取消和失败的终态。页面管理器负责输入、焦点、销毁和资源归还。事件轨通过「游标处添加事件」配置时间和名称。正常向前播放跨过事件时按序派发，暂停续播保留进度，重播重置，预览、Seek 和强制跳过保持静默。回调中关页或取消后停止剩余派发。
- **验收**。0.2 秒和 30 秒动画都能操作，10 倍缩放时非边界区锚点偏差不超过 1 像素。旧动画起点、切点、停顿、终点取样一致。长帧跨过多个事件时各发一次，终点事件先于完成，零时长起止同点只发一次。纯缩放、预览和退出预览无 Prefab 差异。 [当前时间轴视区](../Editor/UI/Animation/UITimelineWorkbench.cs) · [当前转场分支](../Runtime/UI/Management/UITransition.cs) · [Unity 滚轮事件](https://docs.unity3d.com/2022.3/Documentation/Manual/UIE-Mouse-Events.html#WheelEvent)

### OnGUI Debug

- **操作**。通过安全区内可拖动的 FPS 徽标、触摸或桌面快捷键打开。首版包括启动与更新、日志、性能、资源与界面四页。启动与更新页显示本地就绪、当前候选、已加载包版本、下载进度、AOT/DLL 阶段、失败与回退原因。日志可过滤、搜索、暂停跟随、查看堆栈和复制。
- **重做**。采集、诊断快照、OnGUI 三者分开。日志使用单一入口和有界环形缓冲。收起时保留徽标与日志，停止探针。展开时只定频采样可见页。正式配置排除诊断程序集。退役自动生成宿主、`Always` 和强制 GC、卸载资源的通用按钮。自定义面板由装配入口注册只读提供者。
- **验收**。写入 10,000 条唯一日志，准确保留最新 500 条。注入更新或模块失败，仍能打开面板定位。切场景 20 次，关闭 Domain Reload 后 Play/Stop 五轮，始终只有一份订阅。正式 Player 零诊断宿主、订阅和采样。收起时零模块探针，展开时可见页最多 5 Hz。固定 Player 场景对比禁用、收起、展开的 p95 帧耗时和 GC 分配。 [现有 OnGUI 实现](../Runtime/Debugging/RuntimeDebugWindow.cs) · [Unity OnGUI 调用机制](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnGUI.html)

## 4. 实施顺序与放行条件

| 阶段 | 交付 | 放行条件 |
| --- | --- | --- |
| P0 固定基线 | 用空场景、测试 Prefab 和模拟连接建立系统基线。 | 同一提交可重复记录初态、动画取样、页面开关、释放和构建。 |
| P1 UI 操作 | UIState 集中数据与工作台、Timeline 整体缩放。 | 批量编辑、初态隔离、预览、Undo 和缩放全部通过。 |
