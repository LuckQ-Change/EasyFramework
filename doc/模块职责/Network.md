# Network

`NetworkModule` 持有项目装配的 `INetworkTransport`，按帧预算读取并在宿主帧循环中派发连接、断开和消息事件。传输端负责实际连接、收发、解帧及事件队列。使用框架提供的 TCP 时，在模块安装器中声明：

```csharp
composition.Add<NetworkModule>(_ => new NetworkModule(new TcpNetClient()));
```

每个宿主创建自己的传输实例。项目可通过同一入口装配其他传输，传输事件携带连接代数，网络模块会跳过较早连接留下的事件。手动断开后可再次连接，宿主关闭会释放传输实例和未派发事件。

`TcpNetClient` 按 `[4 字节大端正文长度][4 字节大端消息 ID][负载]` 收发，正文长度包含消息 ID 与负载。每次连接独立取消，接收消息超出队列预算时关闭当次连接。心跳、自动重连和业务协议由项目使用模块事件和收发接口实现。
