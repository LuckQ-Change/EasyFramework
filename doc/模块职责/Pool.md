# Pool

`PoolModule` 管理所属宿主的默认池和命名池。`ObjectPool<T>` 在同一线程管理一个类型的空闲对象、借出对象和借还回调。`IPoolable` 提供初始化和重置入口。池负责对象的所有权，创建者通过 `onDestroy` 提供实际的资源释放动作，例如销毁 Unity 对象。

- `Clear` 和 `PoolModule.ClearAll` 销毁空闲对象，保留池登记与借出关系。借出的实例仍可归还到原池。
- `Close` 永久关闭池。宿主关闭时，`PoolModule` 会关闭所有池。借出对象走归还回调与销毁回调，空闲对象直接走销毁回调。回调内触发关闭时，当前正在借还的对象由原操作完成清理。
- 已关闭的池拒绝借出和预热，已关闭的模块拒绝获取和创建池。晚归还直接返回，调用方可在自己的释放逻辑中照常交还旧引用。
- 开放期间，每个归还都须匹配本池中当前借出的实例。默认报告外来、重复和回调中重复归还，关闭 `collectionCheck` 时忽略非法归还。借出或归还回调失败时移除此对象并执行销毁回调。
