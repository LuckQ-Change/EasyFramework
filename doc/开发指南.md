# EasyFramework 开发指南

## 项目定位

- 包名：`com.wjq.easyframework`
- Unity：2022.3 LTS
- 形态：单包、单 Runtime 程序集
- 原则：确定的生命周期、按需注册、明确所有权、主循环低分配

框架刻意不内置 UI、状态机、存档、音频、完整网络协议栈或大型依赖注入容器。资源和热更只提供适配入口，不重复实现 YooAsset、HybridCLR 已解决的问题。

## 目录

```text
Runtime/
  Bootstrap/   Unity 自动启动与模块注册
  Core/        入口、生命周期、日志、模块单例
  Event/       类型安全事件
  Pool/        C# 对象池与命名池
  Utils/       定时器和小型扩展
  NetWork/     TCP 帧传输与主线程派发
  YooAsset/    资源 Loader、租约及 YooAsset 适配
  HybridCLR/   热更 Loader 及 HybridCLR 适配
Editor/        预留编辑器程序集
Tests/Editor/  EditMode 测试
doc/           使用和开发文档
```

## 核心不变量

### 模块生命周期

`ModuleManager` 状态依次为：

```text
Registering → Initializing → Running → ShuttingDown → Stopped
                  │
                  └──────────────→ Faulted
```

- `Register<T>` 只允许在注册阶段或一个安装批次内调用。
- 初始启动和晚到安装都采用“完整注册后统一初始化”。
- 初始化失败必须逆序回滚，且不能残留 `ModuleSingleton.Instance`。
- 更新和关闭错误必须隔离，不能阻断其他模块。
- 模块注册顺序就是初始化/更新顺序，关闭顺序相反；不引入依赖图。

### 所有权

- 池对象只能回收到创建它的池，重复回收视为错误。
- 资源推荐通过 `AssetLease<T>` 持有，最后一个租约决定底层释放时机。
- TCP 接收任务只允许清理自己的连接上下文，旧连接不能影响新连接。

### 可选能力

默认模块只有 Event、Timer、Pool。Asset、Network、Hotfix 代码仍位于同一 Runtime 程序集，但必须由项目显式注册。YooAsset 与 HybridCLR 适配器通过编译宏启用。

## 扩展模块规范

```csharp
public sealed class ExampleModule : ModuleSingleton<ExampleModule>
{
    protected override void OnInit()
    {
        // 获取依赖、订阅事件；失败可抛异常触发启动回滚。
    }

    protected override void OnUpdate(float deltaTime)
    {
        // 主线程逻辑；避免每帧分配。
    }

    protected override void OnShutdown()
    {
        // 必须幂等，释放订阅、句柄和后台任务。
    }
}
```

模块构造函数只做字段初始化，不启动任务、不访问 Unity 场景、不持有外部资源。资源获取放在 `OnInit`，释放放在 `OnShutdown`。

## 测试要求

修改以下区域时至少覆盖相应 EditMode 测试：

- Core：初始化顺序、失败回滚、逆序关闭、晚到安装。
- Event：订阅变更、嵌套派发、处理器异常隔离。
- Pool：重复/外来回收、容量、清理与销毁回调。
- Timer：回调内新增、取消和异常处理。
- Asset：并发加载合并、引用计数、关闭期间完成加载。
- Network：分帧、半包、坏帧、断开重连和发送顺序。

当前测试程序集为 `Tests/Editor/com.wjq.easyframework.tests.asmdef`，通过 Unity Test Runner 运行。

## 发布检查

1. Runtime 在未定义第三方宏时通过编译。
2. 分别安装目标版本 YooAsset、HybridCLR，启用宏验证适配器。
3. EditMode 测试全部通过。
4. 检查 `README.md`、`CHANGELOG.md`、使用文档和 `package.json` 版本一致。
5. 在 Mono 与 IL2CPP Development Build 各做一次最小启动验证。
