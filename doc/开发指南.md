# EasyFramework 开发指南

## 项目定位

- 包名：`com.wjq.easyframework`
- Unity：2022.3 LTS
- 形态：核心 Runtime 加可选适配程序集
- 原则：确定的生命周期、按需注册、明确所有权、主循环低分配

框架刻意不内置具体业务流程、存档、完整网络协议栈或大型依赖注入容器。流程模块只负责注册和切换项目定义的流程；资源和热更只提供适配入口，不重复实现 YooAsset、HybridCLR 已解决的问题。

## 核心不变量

### 模块生命周期

- `Register<T>` 只允许在注册阶段或一个安装批次内调用。
- 初始启动和晚到安装都采用“完整注册后统一初始化”。
- 初始化失败时，逆序关闭已经进入初始化的模块，并移除整个失败批次。
- 更新和关闭错误必须隔离，不能阻断其他模块。
- 初始化按 `Register<T>(order: ...)` 的阶段进行，同阶段的异步初始化可以重叠。Tick 按初始化的启动顺序，关闭按逆序。只有实现 `IFrameUpdate` 的模块才参与 Tick，新批次初始化完成后开始更新。

### 所有权

- 池对象只能回收到创建它的池，重复回收视为错误。
- 通过 `AssetLease<T>` 或 `AssetScope` 持有资源。最后一个租约归还后由空闲缓存策略决定底层释放时机。实例、池中对象和仍在使用的组件引用都需要保留所属租约。
- TCP 接收任务只允许清理自己的连接上下文，旧连接不能影响新连接。

### 可选能力

默认模块为 Event、Timer、Pool、Tween 和 Audio。其余模块可通过 Registrar 按需注册。在 Startup Config 配置资源包或启动流程时，Launcher 会自动注册对应模块。

## 扩展模块规范

```csharp
public sealed class ExampleModule : Module<ExampleModule>, IFrameUpdate
{
    protected override void OnInit()
    {
        // 获取依赖、订阅事件；失败可抛异常触发启动回滚。
    }

    void IFrameUpdate.Tick(float deltaTime)
    {
        // 主线程逻辑；避免每帧分配。
    }

    protected override void OnShutdown()
    {
        // 必须幂等，释放订阅、句柄和后台任务。
    }
}
```

模块构造函数只做字段初始化，不启动任务、不访问 Unity 场景、不持有外部资源。同步初始化放在 `OnInit`，异步初始化放在 `OnInitAsync`，释放放在 `OnShutdown`。

## 隔离验证

在工程外的独立副本验证改动，以下场景可用作回归范围。

- Core：初始化顺序、失败回滚、逆序关闭、晚到安装。
- Event：订阅变更、嵌套派发、处理器异常隔离。
- Pool：重复/外来回收、容量、清理与销毁回调。
- Timer：回调内新增、取消和异常处理。
- Tween：手动推进、时间模式、Sequence 顺序与并行、中断和所有权释放。
- Asset：并发加载合并、引用计数、关闭期间完成加载。
- Network：分帧、半包、坏帧、断开重连和发送顺序。

## 发布检查

1. Runtime 在未定义第三方宏时通过编译。
2. 分别安装目标版本 YooAsset、HybridCLR，启用宏验证适配器。
3. 隔离工程中的相关回归通过。
4. 检查 `README.md`、`CHANGELOG.md`、使用文档和 `package.json` 版本一致。
5. 在 Mono 与 IL2CPP Development Build 各做一次最小启动验证。
