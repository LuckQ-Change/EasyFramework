## 验收步骤存档

本轮手测完成后，已清理 `P0Bootstrap`、`P0Empty`、`P0View`、`P0StartupConfig`、`P0ReferencedPackage`、`P0Message` 以及构建列表中的两条场景条目。以下步骤记录本次基线的操作方式，复跑时需按上面的场景与配置重新准备样例。

1. 编译后打开 `P0Bootstrap`，进入 Play Mode。在 Hierarchy 确认框架创建 UI 宿主和 EventSystem，并检查 Console。
2. 在 Play Mode 确认 Game 视图直接显示样例，再展开 `P0 Preview Canvas > P0View`。检查实例的根控制器初始为 `Disabled`，嵌套控制器为 `Normal`。通过 `Tools > EasyFramework > UI > State Workbench` 切换根状态，观察外层图形在灰白之间切换，嵌套图形保持蓝色。
3. 退出 Play Mode，打开 `P0View` 的 Prefab Mode，选择根 `UITimeline`，点击「打开时间轴工作台」。选择 `Sample` 后分别在 `0`、`0.5`、`1` 秒读取根 `CanvasGroup.alpha` 和 `StateVisual.localScale`。序列化配置的预期透明度分别为 `0.2`、`0.5`、`0.8`，预期每轴缩放为 `1`、`1.5`、`2`。点击「停止并恢复」，记录恢复结果。
4. 退出 Play Mode，打开 `File > Build Settings`。将 `P0Bootstrap` 和 `P0Empty` 加入 `Scenes In Build` 并启用，`P0Bootstrap` 排在第一位。选择 `Windows, Mac, Linux`，将目标平台设为 Windows，架构设为 `Intel 64-bit`（`x86_64`）。如显示 `Switch Platform`，先切换平台。[Unity Windows 构建设置](https://docs.unity3d.com/2022.3/Documentation/Manual/WindowsStandaloneBinaries.html)
5. 在 `Player Settings > Other Settings > Configuration` 确认 `Scripting Backend` 为 `Mono`。复跑本次双场景构建时取消勾选 `Development Build`，使用 `Build/GFProject.exe` 输出路径。记录目标平台、后端、Unity 版本、构建结果、产物路径和运行日志，并核对 Player 窗口中的样例。操作入口参见 [Unity Build Settings](https://docs.unity3d.com/2022.3/Documentation/Manual/BuildSettings.html) 和 [Unity Mono 文档](https://docs.unity3d.com/cn/2022.3/Manual/Mono.html)。

场景画布上的 `P0View` 实例用于观察状态初态。Play Mode 下，`UIRuntimeHost` 的 Inspector 可查看层根节点、已打开页面和页面资源租约，并关闭已打开的顶层页面。运行时场景往返和本机 TCP 回环仍缺少验收结果。
