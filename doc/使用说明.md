# EasyFramework 使用说明

> 适用模块：Core / Event / Pool / Utils / NetWork / YooAsset / HybridCLR。

---

## 一、最快上手

### 零配置启动
**什么都不用做**——只要 `EasyFramework` 在 `Assets/` 下，Unity 加载第一个场景前，框架会通过 `[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)]` 自动：

1. 在场景里创建 `[EasyFramework]` GameObject 并 `DontDestroyOnLoad`
2. 挂上 `EasyFrameworkLauncher` 驱动组件
3. `EasyEntry.Init()` → `ModuleRegistry.ApplyAll()` → 默认 6 个模块 + 业务注册的模块全部就位

业务脚本直接用就行：
```csharp
using EasyFramework;

public class MyGame : MonoBehaviour
{
    void Start()
    {
        TimerModule.Instance.Delay(2f, () => Log.Info("2 秒后到了"));
    }
}
```

### 关闭自动启动
如果你想完全手动控制，加宏 `EASY_NO_AUTO_BOOTSTRAP`，然后自己挂 `EasyFrameworkLauncher` 到场景里即可。两种方式都能跑，启动器会自动判重，不会重复初始化。

## 二、单例约束

所有模块统一继承 `ModuleSingleton<T>`：

```csharp
public class TimerModule : ModuleSingleton<TimerModule> { ... }
```

强制约束：
- **静态访问**：`TimerModule.Instance.Delay(...)` — 不用每次走 `EasyEntry.Modules.Get<>()`。
- **禁止重复实例化**：构造函数检查 `Instance != null` 时抛 `InvalidOperationException`，防止误用 `new TimerModule()`。
- **生命周期闭环**：`OnShutdown` 后 `Instance` 自动置 null，下次 `EasyEntry.Init()` 可以干净重建。
- **驱动方式不变**：仍由 `ModuleManager` 统一驱动 `OnInit/OnUpdate/OnShutdown`，业务代码不能直接调用这三个方法（它们是 `protected override` + 显式接口实现）。

## 三、各模块用法速查

### 3.1 Log
```csharp
Log.Info("hello");
Log.Warn("careful");
Log.Error("boom");
Log.MinLevel = LogLevel.Warn; // 过滤掉 Debug/Info
```

### 3.2 TimerModule
```csharp
int id1 = TimerModule.Instance.Delay(3f, () => Log.Info("单次"));
int id2 = TimerModule.Instance.Loop(1f, () => Log.Info("循环"));

TimerModule.Instance.Cancel(id2);
TimerModule.Instance.CancelAll();
```

### 3.3 EventModule
```csharp
public struct PlayerDieEvent : IEvent { public int PlayerId; }

Action<PlayerDieEvent> handler = e => Log.Info($"player {e.PlayerId} died");
EventModule.Instance.Subscribe(handler);
EventModule.Instance.Dispatch(new PlayerDieEvent { PlayerId = 1 });
EventModule.Instance.Unsubscribe(handler);
```
注意：`Unsubscribe` 要传同一个委托引用，匿名 lambda 退订要先存变量。

### 3.4 PoolModule
```csharp
public class Bullet : IPoolable
{
    public void OnSpawn()   { /* reset */ }
    public void OnDespawn() { /* cleanup */ }
}

var b = PoolModule.Instance.Spawn<Bullet>();
PoolModule.Instance.Despawn(b);
```

### 3.5 NetworkModule
```csharp
NetworkModule.Instance.OnConnected    += () => Log.Info("connected");
NetworkModule.Instance.OnDisconnected += reason => Log.Warn($"disconnected: {reason}");
NetworkModule.Instance.OnMessage      += msg => Log.Info($"recv id={msg.MsgId} len={msg.Payload.Length}");

await NetworkModule.Instance.ConnectAsync("127.0.0.1", 9000);
NetworkModule.Instance.Send(1001, System.Text.Encoding.UTF8.GetBytes("hello"));
```
所有回调都在主线程触发，可以直接操作 Unity 对象。

### 3.6 AssetModule
**未装 YooAsset**：用内存实现做调试
```csharp
var mem = new MemoryAssetLoader();
mem.Add("Prefabs/Bullet", somePrefab);
AssetModule.Instance.SetLoader(mem);
await AssetModule.Instance.InitializeAsync();
var go = await AssetModule.Instance.LoadAsync<GameObject>("Prefabs/Bullet");
```
**装了 YooAsset**：加宏 `EASY_YOOASSET`，把 loader 换成真实实现
```csharp
AssetModule.Instance.SetLoader(new YooAssetLoader("DefaultPackage", YooAsset.EPlayMode.OfflinePlayMode));
```

### 3.7 HotfixModule
```csharp
#if EASY_HYBRIDCLR
HotfixModule.Instance.SetLoader(new HybridCLRLoader());
#endif

HotfixModule.Instance.LoadAotMetadata(new[] { aotDllBytes1, aotDllBytes2 });
var asm = HotfixModule.Instance.LoadHotfix(hotUpdateDllBytes);
HotfixModule.Instance.InvokeEntry(asm, "HotUpdate.GameMain", "Start");
```

### 3.8 Utils
```csharp
list.IsNullOrEmpty();
list.RandomItem();
list.Shuffle();
dict.GetOrAdd(key, k => new Value());

str.IsNullOrEmpty();
str.Or("default");

int id = IdGenerator.Next();
```

## 四、自定义模块

任何类继承 `ModuleSingleton<T>` 就能挂进框架：

```csharp
public class SaveModule : ModuleSingleton<SaveModule>
{
    protected override void OnInit()                  { /* 读档 */ }
    protected override void OnUpdate(float deltaTime) { /* 每帧 */ }
    protected override void OnShutdown()              { /* 存档 */ }

    public void Save(string key, string value) { /* ... */ }
}
```

注册方式（推荐 A，不用挂任何东西）：

**方式 A：写一个静态注册入口（零侵入）**
```csharp
using EasyFramework;
using UnityEngine;

public static class GameModuleBootstrap
{
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    private static void Register()
    {
        ModuleRegistry.AddRegistrar(modules =>
        {
            modules.Register<SaveModule>();
            // modules.Register<其它你的模块>();
        });
    }
}
```
框架自动启动时会顺序应用所有注册器，业务代码不需要碰场景、不用继承 MonoBehaviour。

**方式 B：直接修改 `ModuleRegistry.RegisterDefault`**
只适合"框架自带"性质的模块——业务代码不要往里写。

调用：
```csharp
SaveModule.Instance.Save("score", "100");
```

## 五、生命周期顺序

```
[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]
  └─ ModuleRegistry.ClearRegistrars()          // 域重载关闭场景下清旧状态

[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)]
  └─ 业务侧 ModuleRegistry.AddRegistrar(...)   // 用户注册自定义模块
  └─ EasyFrameworkBootstrap.AutoStart
        └─ new GameObject("[EasyFramework]") + AddComponent<Launcher>

EasyFrameworkLauncher.Awake
  └─ Log.Handler → UnityEngine.Debug
  └─ EasyEntry.Init                    // 创建 ModuleManager
  └─ ModuleRegistry.ApplyAll
        ├─ RegisterDefault             // 6 个默认模块
        └─ 应用业务注册器               // 用户自定义模块

每帧:
EasyFrameworkLauncher.Update → EasyEntry.Update → 各模块 OnUpdate

退出/销毁:
Launcher.OnApplicationQuit / OnDestroy → EasyEntry.Shutdown
  └─ 各模块逆序 OnShutdown，Instance 自动清空
```

> 注意：业务侧注册器和框架自动启动都跑在 `BeforeSceneLoad`，Unity 文档对同一阶段内的执行顺序不保证。**但这不影响正确性**——业务注册器只是把 `Action<ModuleManager>` 塞进 `_extraRegistrars` 列表，等启动器 Awake 时再统一应用。先后跑都行。

## 六、常见坑

| 现象 | 原因 / 解决 |
| --- | --- |
| `XxxModule.Instance` 是 null | 业务脚本早于启动器 Awake 运行。启动器已设 `[DefaultExecutionOrder(-1000)]`，业务侧用 `Start()` 拿模块就好。 |
| `new XxxModule()` 直接抛异常 | 设计就是这样：所有模块都是单例，必须经 `ModuleManager.Register` 进入。 |
| Console 看不到错误红字 | 确认场景里挂的是 `EasyFrameworkLauncher`，且没人后续覆盖 `Log.Handler`。 |
| YooAsset / HybridCLR 编译报错 | 没装包但加了 `EASY_YOOASSET` / `EASY_HYBRIDCLR` 宏。去宏或装包。 |
| `NetworkModule` 收不到消息 | 服务器协议帧必须是 `[4字节大端长度][4字节大端MsgId][payload]`，否则被判坏帧断开。 |
