# 启动流程、运行模式与全局 Loading

## 默认流程

框架启动后按以下顺序运行：

```text
StartupProcedure
  -> ResourceProcedure
  -> HotUpdateProcedure
  -> PreloadProcedure
  -> LoginProcedure
  -> GameProcedure
  -> ExitProcedure
```

- Startup：创建 UI 根节点、相机和 EventSystem，打开全局 Loading。
- Resource：按运行模式初始化项目注入的资源 Loader。
- HotUpdate：Online 模式加载 AOT metadata、热更程序集并调用入口。
- Preload：预加载 UI，随后关闭启动 Loading。
- Login：打开登录 UI 并停留，等待登录成功。
- Game：关闭登录 UI，打开游戏 UI并停留。
- Exit：关闭 UI、释放预加载与资源，可选择退出应用。

登录成功和退出游戏时切换流程：

```csharp
await ProcedureModule.Instance.EnterGameAsync();
await ProcedureModule.Instance.ExitGameAsync();
```

自定义流程继承 `ProcedureBase`，通过 `ProcedureModule.Register<T>()` 注册；返回下一个 Procedure 类型会自动继续，返回 `Stay()` 则停留等待外部切换。

## 运行模式

启动预设的 Runtime Mode 在模块初始化前写入 `EasyRuntime.Mode`：

- Editor：编辑器直连资源，跳过程序集热更。
- Online：在线资源并执行已配置的热更。
- Offline：本地/单机资源，跳过热更。
- Web：Web 资源 Loader，跳过当前动态程序集热更。

项目按模式注入具体 Loader：

```csharp
[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
private static void ConfigureResources()
{
    ModuleRegistry.AddRegistrar(modules =>
    {
        AssetModule assets = modules.Register<AssetModule>();
        assets.SetLoader(CreateLoader(EasyRuntime.Mode));
    });
}
```

预设中只要配置了热更、预加载 UI、Login View 或 Game View，就必须提供资源 Loader；空预设可以不配置 Loader，流程会直接进入 Login。

## 启动预设

通过 `Assets/Create/EasyFramework/Startup Preset` 创建预设，场景 Launcher 可直接引用；自动 Launcher 会读取 `Resources/EasyFrameworkStartupPreset.asset`，找不到时使用内置默认预设。

主要配置包括：

- Runtime Mode、是否自动启动 Procedure Flow。
- UI Render Mode、UI Camera、UI Layer、Canvas Scaler、共享背景。
- Loading Display（内容 Prefab、Overlay Canvas、Sorting Order 和 Canvas Scaler；不依赖 EasyUIDisplay 或 EasyUIManager）。
- AOT metadata、热更程序集、入口类型和方法。
- 预加载 UI、Login View、Game View 地址。
- Exit 时是否调用 `Application.Quit()`。

全局 Loading 在 Resource、HotUpdate、Preload 三个阶段保持同一个会话，避免阶段切换时反复闪烁。空流程也会按 Unity 实际运行帧平滑补齐进度并至少显示两秒；真实启动耗时超过两秒时不会追加等待。
